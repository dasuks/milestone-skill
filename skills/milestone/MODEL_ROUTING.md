# 모델 라우팅

마일스톤 계획에서 작업마다 등급을 붙인다. 모델 이름은 이 파일에만 둔다. 모델이 바뀌면 이 파일만 고친다.

| 등급 | 성격 | Claude | Codex |
|---|---|---|---|
| [자동] | 결과가 매번 같아야 하는 기계적 반복 | 스크립트·기존 명령 | 스크립트·기존 명령 |
| [반복] | 단순 반복, 일상 작업 | Sonnet 5 (`claude-sonnet-5`) | `gpt-6-sol` 낮은 추론 설정 |
| [구현] | 할 일과 통과 기준이 정해진 작업 | Opus 5.5 (`claude-opus-5-5`) | `gpt-6-sol` 중간~높은 추론 설정 |
| [판단] | 설계, 계약, DB, 보안, 원인 모를 버그, 애매한 요구 | Fable 5.1 (`claude-fable-5-1`) | `gpt-6-astra` |
| [검수] | 구현한 쪽의 반대 회사 | Fable 5.1 | `gpt-6-astra` (지적만) |

- 반복 작업은 먼저 스크립트로 되는지 본다. 되면 [자동], 안 되면 [반복].
- 워커가 스펙에 없는 결정이 필요하다고 보고하면 [판단]으로 올려 다시 배정한다.
- 근거(2026-09-25): Artificial Analysis Intelligence Index 최대 설정 기준 Opus 5.5 58, gpt-6-sol 48, Sonnet 5 38. sol(xhigh)은 AutomationBench에서 Opus 5.5(medium)와 비슷한 점수를 약 40% 비용으로 낸다.
